# 作业管理系统 — 界面设计规范文档

## 一、项目概述

桌面端作业管理系统，分为**学生端**和**教师端**两个角色界面。基于 Qt6 桌面框架，窗口尺寸 800×600。

---

## 二、设计风格

沿用已有的登录/注册页面视觉风格：

| 项目 | 规范 |
|------|------|
| 主色调 | `#3B82F6`（蓝色），hover `#2563EB`，pressed `#1D4ED8` |
| 背景色 | `#F8FAFC`（浅灰白） |
| 卡片/面板背景 | `#FFFFFF`（纯白） |
| 主文字色 | `#1E293B`（深灰黑） |
| 次要文字色 | `#64748B`（中灰） |
| 占位/提示文字 | `#94A3B8`（浅灰） |
| 边框色 | `#E2E8F0` |
| 错误/警告色 | `#EF4444`（红色） |
| 成功色 | `#22C55E`（绿色） |
| 圆角 | 8px（按钮、输入框、卡片） |
| 字体 | 系统默认，标题 bold 28px，正文 14px，次要 12px |
| 按钮风格 | 蓝色实心圆角按钮，白色文字，hover 变深 |

│            │                                             │

### 顶部栏

| 元素 | 位置 | 样式 |
|------|------|------|
| 系统标题 | 左侧 | "作业管理系统"，16px bold，`#1E293B` |
| 用户名 | 右侧 | 显示当前登录用户名，14px，`#64748B` |

| 元素 | 样式 |
|------|------|
| 菜单项 | 高度 44px，padding-left 20px，14px 字号 |
| 默认状态 | 文字 `#64748B`，背景透明 |

## 七、交互规范

| 交互 | 说明 |
|------|------|
| 按钮 hover | 背景色加深一级 |
| 按钮 loading | 点击后按钮文字变为 "...处理中"，禁用防止重复点击 |
| 网络错误 | 右上角红色 Toast 提示 "网络错误，请检查连接"，3 秒消失 |
| 操作成功 | 右上角绿色 Toast 提示，2 秒消失 |
| 删除确认 | QMessageBox 二次确认，标题 "确认删除"，内容说明后果 |
| 截止时间过期 | 时间文字变红，卡片左侧加红色竖条 |
| 提交后 | 自动跳转到详情页已提交状态，或刷新列表更新状态标签 |
